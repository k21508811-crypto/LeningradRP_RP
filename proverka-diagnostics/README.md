# Proverka Diagnostics

Windows x64 diagnostic utility for GTA V Legacy, RAGE Plugin Hook and LSPDFR.

The app reads game files, plugin locations and available .log files. It does not patch, delete, or modify game files. It reports known signatures such as missing RAGE Plugin Hook plugin attributes, assembly-load failures, and LSPDFR outfit warnings. These are diagnostic hints, not guaranteed root-cause detection.

Build: GitHub Actions workflow "Build Proverka Diagnostics". Download artifact "ProverkaDiagnostics-Windows-x64".
