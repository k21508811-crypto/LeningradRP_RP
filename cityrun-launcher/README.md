# City Run PC Demo + Launcher

This branch builds a portable Windows demo package containing:
- A standalone dark/red desktop launcher.
- The current City Run 3D one-mission prototype.
- A relative-path check that enables Play only when the game executable is present.
- A portable folder layout; keep Launcher and Game folders together.

## Build
GitHub Actions workflow: `.github/workflows/build-cityrun-pc-demo.yml`.
Artifact: `CityRun-PC-Demo-with-Launcher`.

## Important
This is an early original prototype, not a full AAA open-world game and not a copy of GTA V. The launcher does not pretend that an online license server or updater exists. The current build is a functional local launcher for the included Windows demo.
