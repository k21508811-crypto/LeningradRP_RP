# City Stories — Chapter 01 (PC prototype)

An original, small 3D city mission inspired by open-world action games. This is **not GTA V** and does not include Rockstar assets, maps, characters, music, or code.

## Run it
1. Install Godot 4.3 or newer.
2. Open this folder in Godot.
3. Press F6 or F5 to run the project.

## Controls
- WASD / arrow keys: move or drive
- Mouse: camera
- E: enter / leave the car
- Esc: release / capture mouse

## Mission
Reach the meeting point, approach the blue car, enter it, then drive to the marked parking lot. The mission ends when you reach the destination.

## Current prototype scope
The city, buildings, character, car, marker and HUD are generated with primitive 3D meshes at runtime. This is a playable starter prototype, not a finished commercial-scale GTA-like game. Next steps: replace placeholder geometry with original assets, add animation, audio, traffic, pedestrians, save system and mission cinematics.
