# Ленинград RP

Мобильная стартовая страница для Roblox-игры **Ленинград RP**.

## Запуск

Откройте `index.html` в браузере или разместите все файлы в корне статического сайта.

Кнопка «ИГРАТЬ» открывает игру:
https://play.roblox.com/games/start?placeId=86706967486022

Для запуска игры на устройстве должен быть установлен Roblox.

## Файлы

- `index.html` — разметка страницы.
- `style.css` — чёрно-красное оформление.
- `script.js` — автоматическое отображение текущего года.

> Это исходники веб-лаунчера, а не готовый подписанный APK-файл.
