# City Run — Enhanced One-Mission PC Prototype

An original 3D city-driving mission prototype made with Godot 4.3. The visual pass adds filmic tonemapping, glow, distance fog, directional shadows, reflective red-car paint, illuminated building windows, street lamps and trees.

## Mission: The Last Delivery
1. Find the red car and press **E** to enter.
2. Drive through the three glowing yellow checkpoints.
3. Reach the final garage area to complete the delivery.

## Controls
- **WASD** — walk / drive
- **Mouse** — look around / steer
- **E** — enter or leave the car
- **Esc** — release the mouse cursor

## Run locally
Install Godot 4.3 or newer, open this folder as a project, and press Play.

## Windows build
Open the repository **Actions** tab and download the `CityRun-Windows` artifact after the workflow succeeds. Extract the ZIP and run `CityRun.exe`.

## About the requested 1 GB size
The project is being improved with real game content, not artificial padding. A 1 GB download should come from useful assets such as high-resolution original textures, detailed environment meshes, character and vehicle models, animations, audio, and cinematic sequences. This prototype currently uses procedural placeholder geometry, so forcing it to 1 GB would only waste storage and bandwidth without improving the game. The final download size will be set by the actual asset pack.

This is an original prototype inspired by open-world action games. It does not include GTA V assets, maps, characters, music, or code, and does not bypass any game's DRM or licensing.
