# City Run — One Mission PC Prototype

An original 3D city-driving mission prototype made with Godot 4.3. It is inspired by open-world action games, but uses original code and placeholder geometry.

## Mission: The Last Delivery
1. Find the red car and press E to enter.
2. Drive through the three glowing yellow checkpoints.
3. Reach the final garage area to complete the delivery.

## Controls
- WASD — walk / drive
- Mouse — look around / steer
- E — enter or leave the car
- Esc — release the mouse cursor

## Run locally
Install Godot 4.3 or newer, open this folder as a project, and press Play.

## Windows build
Open the repository Actions tab and download the CityRun-Windows artifact after the workflow succeeds. Extract the ZIP and run CityRun.exe.

This is an early prototype with procedural placeholder buildings and a simple vehicle controller. It does not include GTA V assets, maps, characters, music, or code, and does not bypass any game's DRM or licensing.
