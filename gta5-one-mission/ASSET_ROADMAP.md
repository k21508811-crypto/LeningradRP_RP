# City Run content and quality roadmap

## Implemented in the current prototype
- Filmic tonemapping, fog, glow and directional shadows
- Procedural city blocks with illuminated facade windows
- Street lamps, trees and sidewalk dressing
- Player vehicle with wheels, glass cabin, headlights and tail lights
- Eight simple ambient traffic vehicles
- Three-step delivery mission with an actual parcel pickup interaction
- Windows export workflow with an explicit output-file validation step

## Remaining production stages
1. Replace blockout geometry with original, optimized 3D building and street assets.
2. Add original detailed player and vehicle models, UVs, materials and LODs.
3. Add pedestrian characters, simple schedules and non-combat ambient interactions.
4. Add original engine, tire, city ambience, footsteps and mission audio.
5. Expand the district with interiors, a garage, a pickup location and more road layouts.
6. Add mission cinematics, checkpoints, save/load and settings.
7. Profile on target PCs, optimize draw calls, collision shapes, texture memory and streaming.
8. Build and test Windows release packages on clean machines.

## About a 1 GB release
The prototype is not a 1 GB game yet. The target size should be reached only through real, licensed game content: high-resolution textures, original models, audio, animations and optional cinematic media. Do not pad the download with duplicate or meaningless data. Use LODs, mipmaps and compression so a larger content library does not make the game unnecessarily slow.

## Asset licensing
Use original assets or assets whose licenses explicitly allow redistribution in a game. Do not import GTA V/Rockstar game files, ripped models, maps, textures, sounds or music.
